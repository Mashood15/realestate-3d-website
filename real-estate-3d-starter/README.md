# Real Estate 3D Website Starter Assets

This folder is an implementation brief and asset drop-zone for a Next.js static-export website.

## Included
- `REAL_ESTATE_3D_WEBSITE_BRIEF.md`: complete instructions to give your IDE coding agent.
- `public/models/`: place licensed `.glb` models here.
- `public/textures/`: place textures/HDRIs here.
- `docs/ASSET_MANIFEST.json`: asset slots and expected filenames.

## Important
No third-party 3D models are bundled in this starter. The brief instructs the IDE to create a procedural villa in code so the website runs immediately, even before you source a production-quality model.

Suggested first model filename: `public/models/villa.glb`
